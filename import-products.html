Import Product Lists

Import your full product catalog from a CSV — any mix of categories (Cakes, Shells, Fountains, Comets, Finale Chains, and so on), straight from a supplier's price list export. Imported items show up in the Catalog page right away, grouped by category and ready to search or add to a show plan.

PRODUCTS

Columns: Class, Category, Product Name, Brand, Price, Description, Product URL

Class is the firework classification (1.3 for display/professional, 1.4 for consumer). Category can be anything your supplier uses — "Cakes", "Shells 3in", "500 Gram Cakes", "Fountains", "Comets", "Finale Chains", etc. — the Catalog page groups and filters by whatever shows up here.

⬇ Download template

Importing adds rows as new catalog entries — importing the same file twice will create duplicates, so remove a row in the Catalog page if you need to undo one.
